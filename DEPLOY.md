# FreeStack Production Deployment & CDN Guide (`DEPLOY.md`)

This guide documents how to run **FreeStack** in production and configure Cloudflare (or any reverse proxy / CDN) for optimal caching, compression, HTTP/2 & HTTP/3 delivery, and security.

---

## 1. Production Build & Startup

```bash
# 1. Install production + build dependencies cleanly
npm ci --ignore-scripts

# 2. Run full verification (TypeScript, unit/parity tests, data validation, build, perf budgets)
npm run verify

# 3. Start the production Express server
NODE_ENV=production PORT=3000 SITE_URL=https://freestack.dev npm run start:prod
```

### Build Outputs
- `src/lib/data/homeBootstrap.json`: Generated at build time by `scripts/build-bootstrap.ts` (~4.9 KB gzip).
- `dist/assets/*`: Content-hashed JS and CSS bundles, plus precompressed `.gz` (gzip level 9) and `.br` (Brotli quality 11) companions generated by `scripts/precompress-dist.ts`.
- `dist-server/server.js`: Bundled ESM Express server (`esbuild --format=esm`).

## 2. Origin Cache-Control & Compression Behavior

The Express server (`src/lib/server/createApp.ts`) sets explicit `Cache-Control`, `ETag`, `Vary: Accept-Encoding`, and Brotli/Gzip compression headers out of the box:

| Path Pattern | Origin `Cache-Control` | Compression | Notes |
| :--- | :--- | :--- | :--- |
| `/assets/*` | `public, max-age=31536000, immutable` | Precompressed `.br` / `.gz` from disk | Content-hashed Vite JS/CSS chunks |
| `/logos/*` | `public, max-age=31536000, immutable` | Static SVG/PNG/JPG (`<= 5 KB` each) | 1,398 same-origin optimized brand logos |
| `/fonts/*` | `public, max-age=31536000, immutable` | WOFF2 (already Brotli-compressed) | Self-hosted Latin variable fonts |
| `GET /api/offers` | `public, max-age=300, stale-while-revalidate=86400` + weak `ETag` | Runtime Brotli (`br`) / Gzip (`gzip`) | Supports `If-None-Match` -> `304 Not Modified` |
| `GET /api/offers/:slug` | `public, max-age=300, stale-while-revalidate=86400` + weak `ETag` | Runtime Brotli (`br`) / Gzip (`gzip`) | Single offer detail + related offers |
| `/robots.txt`, `/sitemap.xml` | `public, max-age=3600` + `ETag` | Runtime Brotli (`br`) / Gzip (`gzip`) | Generated from `SITE_URL` |
| `GET /api/health`, `/api/reports`, `/go/:slug` | `no-store` | Uncached | Dynamic health, moderation queue, and outbound redirects |
| HTML Routes (`/`, `/explore`, `/offer/*`) | `no-cache` + `ETag` | Runtime Brotli (`br`) / Gzip (`gzip`) | Always revalidates ETag so new deploys take effect immediately |

## 3. Recommended Cloudflare Configuration

### A. Protocol & Compression Settings
1. **HTTP/2 & HTTP/3 (QUIC)**: Enable both **HTTP/2** and **HTTP/3 (with QUIC)** + **0-RTT Connection Resumption** in Cloudflare *Network* settings.
2. **Brotli Compression**: Enable **Brotli** in Cloudflare *Speed -> Optimization*.
3. **Early Hints**: Enable **Early Hints** so Cloudflare emits `103 Early Hints` for the `<link rel="preload" as="font">` headers in `index.html`.

### B. Cloudflare Cache Rules
Configure the following Cache Rules in order:

1. **Bypass Cache for Dynamic Mutations & Redirects**
   - **Match**: `URI Path` starts with `/api/reports` OR `/api/health` OR `/go/`
   - **Action**: *Bypass cache*
2. **Edge Cache Catalog Read APIs (`/api/offers*`)**
   - **Match**: `URI Path` starts with `/api/offers` AND `Request Method` in `{"GET", "HEAD"}`
   - **Action**: *Eligible for cache* -> *Respect Origin Cache-Control* (`max-age=300, stale-while-revalidate=86400`). Include full query string in Cache Key.
3. **Immutable Static Assets (`/assets/*`, `/logos/*`, `/fonts/*`)**
   - **Match**: `URI Path` starts with `/assets/` OR `/logos/` OR `/fonts/`
   - **Action**: *Eligible for cache* -> *Respect Origin Cache-Control* (`max-age=31536000, immutable`).

## 4. Environment Variables & Reverse Proxy Trust

When running behind Cloudflare, Cloud Run, or nginx:
- Set `TRUST_PROXY=1` so `express-rate-limit` reads the client IP from `X-Forwarded-For`.
- Set `SITE_URL=https://<your-domain>` and `STRICT_SITE_URL=true` so canonical links, OpenGraph tags, `robots.txt`, and `sitemap.xml` use the exact production origin.
- Keep `ADMIN_TOKEN` set to a high-entropy secret (`>= 32` characters) if enabling `GET /api/reports`.
